# System Components Frontend

Фронтенд для сервиса расчета задержек компонентов распределенной системы.

## Страницы

- **Каталог компонентов (`/`)** — плитка всех опубликованных компонентов. Здесь можно искать по названию, фильтровать по слоям (Бэкенд, Кэш, БД) и приоритетам. Авторизованный пользователь может удалять свои карточки.
- **Лента (`/feed`)** — детальный просмотр компонента с фото или демонстрационным видео. Можно ставить лайки и переходить к следующему узлу по кнопке «Далее».
- **Создание компонента (`/add`)** — добавление новой карточки в два шага: сначала название и загрузка файлов (черновик), затем описание, выбор слоя, приоритета и публикация. Доступно после входа.
- **Вход (`/login`)** — страница авторизации по логину и паролю для доступа к добавлению и удалению компонентов.

## Лабораторная 7

### Запуск с Go API и доступ с телефона

1. В репозитории `system_components` переключитесь на `lab7`, запустите хранилища и дождитесь готовности PostgreSQL. Миграция добавляет демонстрационные данные в пустую БД.

   ```sh
   git switch lab7
   docker compose up -d postgres redis minio
   go run ./cmd/migrate
   go run ./cmd/system_components
   ```

2. В этом репозитории используйте Node.js 22. Определите IP ноутбука в сети Wi-Fi (на macOS обычно `ipconfig getifaddr en0`). Передайте свой IP при создании сертификата.

   ```sh
   git switch lab7
   npm ci
   npm run generate-cert -- 192.168.1.42
   npm run build
   npm run serve:https
   ```

3. Подключите телефон к той же Wi-Fi сети. Передайте на телефон `ca.crt` и установите его как доверенный корневой сертификат. На iOS включите полное доверие к нему в настройках доверия сертификатам. На Android установите его как сертификат CA через настройки безопасности. Откройте `https://<IP-ноутбука>:8443/`. Если IP сменится, повторите генерацию серверного сертификата с новым IP и перезапустите прокси. Скрипт переиспользует локальный CA.

Node.js раздаёт сборку и передаёт `/api/*` и `/static/*` в Go на `127.0.0.1:8080`, а файлы из `/system-components/*` в MinIO на `127.0.0.1:9000`. Для демонстрации можно войти под учётной записью из начальных данных миграции. Раздел «Добавление» загружает существующий черновик пользователя либо предлагает создать новый, если черновика нет.

### GitHub Pages и PWA

Основной способ публикации — [Settings → Pages](https://github.com/Ilyadevj/system-components-frontend/settings/pages), **Source → GitHub Actions**. Workflow **Deploy lab7 to GitHub Pages** запускается при push в `lab7`. После первоначальной настройки можно перезапустить последний запуск для `lab7` во вкладке **Actions** или отправить следующий коммит в эту ветку. Если у окружения `github-pages` ограничен список веток, добавьте `lab7` в разрешённые.

При публикации из ветки выберите **Source → Deploy from a branch → gh-pages → /(root)**. Для обновления сборки в этой ветке выполните `npm ci` и `npm run deploy` из `lab7`. GitHub Pages для закрытого репозитория требует подходящий тариф GitHub.

Адрес после успешной публикации — [ilyadevj.github.io/system-components-frontend/](https://ilyadevj.github.io/system-components-frontend/). Для локальной проверки той же сборки выполните:

```sh
npm run build:gh-pages
npm run preview -- --mode gh-pages
```

Откройте `http://localhost:4173/system-components-frontend/`. В сборке Pages все действия используют mock-данные. После первого онлайн-запуска офлайн доступны интерфейс, каталог и изображения. Для видео требуется соединение. В Chrome или Safari на телефоне установите PWA через меню браузера, примените фильтр, откройте карточку и вернитесь в плитку. Выбранный фильтр сохраняется до выхода из приложения или сброса.

### Адаптивность

В каталоге 1 колонка до 460 px, 2 до 768 px, 3 до 1024 px и 4 на более широком экране. Обложка карточки сохраняет пропорцию 16:10. В ленте на телефоне видео занимает доступную высоту экрана, а на широком экране ширина ограничена 960 px. Редактор складывает поля в один столбец на телефоне и располагает группы полей рядом на широком экране. Для показа откройте DevTools в режиме устройства и проверьте ширины 320, 545, 768, 1024 и 1440 px.
