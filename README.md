# Фронтенд веб-сервиса «Компоненты распределенной системы»

Веб-приложение на **React**, **TypeScript**, **Vite** и **Redux Toolkit** для каталога и управления компонентами серверной архитектуры.

---

## Страницы приложения

### 1. Каталог компонентов («Плитка») — `/` (`/system-components`)
Главная страница со списком всех опубликованных компонентов:
- Карточки с медиафайлами (изображения/видео) и количеством лайков.
- Фильтрация по поисковой строке (название), архитектурным слоям (`Бэкенд`, `Кэш`, `БД`) и приоритету.
- Отображение авторства и кнопка удаления для собственных компонентов авторизованного пользователя.

### 2. Лента («Подробнее») — `/feed` (`/feed/:id`)
Страница детального просмотра компонента:
- Просмотр полноразмерного изображения или видеодемонстрации узла системы.
- Индикатор и кнопка постановки/снятия лайка.
- Кнопка «Далее» для последовательного перехода к следующему опубликованному компоненту.

### 3. Редактор / Добавление компонента («Черновик») — `/add` (`/editor`)
Двухэтапная форма создания компонента (доступна только авторизованным пользователям):
- **Шаг 1:** Ввод названия компонента и загрузка медиафайлов (картинка и видео) в хранилище MinIO с созданием черновика.
- **Шаг 2:** Заполнение подробного описания, выбор архитектурного слоя (группировки), приоритета и публикация в общий каталог.

### 4. Авторизация («Вход») — `/login`
Страница входа в систему:
- Форма ввода логина и пароля пользователя.
- Аутентификация через API бэкенда с сохранением сессии.
- Переключение прав доступа интерфейса: разблокировка создания компонентов, кнопок удаления и возможность выхода.

---

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev
```

Приложение доступно по адресу: `http://localhost:3000/`.
